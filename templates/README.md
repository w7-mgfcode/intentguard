# FPAT Lite templates

**Purpose:** Provide short artifacts that humans and agents can complete without
inventing metadata.

**Intended reader:** Anyone recording FPAT Lite work.

**Consult this when:** A command needs a persistent artifact.

| Need | Template | Suggested working path |
|---|---|---|
| Capture a request | [request.md](request.md) | `.fpat/request.md` |
| Compare options | [brainstorm.md](brainstorm.md) | `.fpat/brainstorm.md` |
| Plan implementation | [implementation-plan.md](implementation-plan.md) | `.fpat/plan.md` |
| Define one task | [task.md](task.md) | Issue body or plan section |
| Record checks | [validation-report.md](validation-report.md) | `.fpat/validation.md` |
| Review and draft a PR | [review-and-pull-request.md](review-and-pull-request.md) | PR draft or response |
| Preserve state | [handoff.md](handoff.md) | `.fpat/handoff.md` |
| Explain a durable choice | [decision-record.md](decision-record.md) | Project decisions folder |

Use only the templates the task needs. Replace helper prompts with verified
content, delete empty optional sections, and keep facts, assumptions, decisions,
evidence, and unresolved questions visibly separate.
