# FPAT Lite rules

**Purpose:** Identify the small set of rules that all FPAT Lite commands share.

**Intended reader:** Agents and developers performing repository work.

**Consult this when:** Starting a session or resolving a workflow conflict.

Read in this order:

1. [Core rules](core-rules.md) — the 15 stable invariants.
2. [Safety and approval](safety-and-approval.md) — mutation classification and
   approval rules.
3. [Engineering and validation](engineering-and-validation.md) — editing,
   testing, Git, and evidence rules.

The rules are intentionally short. Project-specific instructions may add
constraints, but they may not silently weaken safety, evidence, or user-change
preservation.
