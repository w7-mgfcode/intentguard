# C08.3 — Validate the five-minute delivery path

## Objective

Run a reviewer-oriented walkthrough from README to real-artifact demo and final evidence, then correct documentation-only inconsistencies.

## Rationale

The finished repository should communicate the system quickly without redesign or tribal knowledge.

## Parent identifier

U08.

## Source task

T-008.

## Traceability

Primary ownership is task-local under U08; supports NFR-010, AC-013, and AC-014.

## Prerequisites

C08.1/C08.2 drafted; U06 demo and U07 verdict complete.

## Likely files

`README.md`, `docs/OPERATIONS.md`, `docs/IMPLEMENTATION_STATUS.md`, `docs/LIMITATIONS.md`, demo instructions.

## Implementation boundary

Documentation and demonstration consistency review only; code defects return to their owning umbrella.

## MUST scope

Fresh-reader navigation, setup expectations, command accuracy, real artifact identity, evidence links, status/limitation coherence, time-boxed walkthrough.

## Explicit non-goals

Feature fixes hidden in docs work, optional polish, videos, hosted demo, or fake response capture.

## Acceptance criteria

A reviewer can explain the lifecycle, distinguish baseline/model/threshold, locate evidence, and run/observe the real-artifact demo in five minutes excluding prerequisites.

## Validation commands

`uv run python scripts/validate_foundation.py && make demo` plus a timed documentation walkthrough.

## Expected evidence

Walkthrough checklist, valid links, real artifact ID in demo output, and final documentation consistency review.

## Fallback and status consequence

A mock or undocumented manual path fails this task; optional presentation polish may remain Planned.

## Stop condition

Stop for code defect, missing real artifact, broken command, unsupported claim, or walkthrough exceeding the boundary because essential context is absent.

## Definition of ready

All implementation/evidence is final and the demo environment is available.

## Definition of done

The time-boxed walkthrough succeeds and all documents agree with the strict-MVP verdict.

## Labels

`type:task`, `priority:MUST`, `area:documentation`

## Estimate

0.5 hour.
